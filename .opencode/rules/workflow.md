# Workflow Rules

Never implement large features in one step.

Work incrementally.

For every task:

1. Analyze requirement.
2. Identify impacted modules.
3. Explain implementation plan.
4. Implement.
5. Verify.
6. Report.

After completion:

Provide:

- Files Created
- Files Modified
- Dependencies Added
- Decisions Made
- Verification Performed
- Recommended Next Steps

Stop and wait for approval.

Do not continue automatically.

Exception: when the task explicitly requests autonomous completion
(e.g. "stop only after X is complete and verified"), continue through
verification and the final report without intermediate approvals.
